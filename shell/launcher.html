The Deck Host

Runtime gate only. ROMs live in their own projects and call The Deck Host with --url and optional --spawn. This host does not store ROM files.

No ROMs bundled here Launch from the ROM island (e.g. loreBOX prod/run-loreBOX.bat)

Example: python deck_host.py --url http://127.0.0.1:PORT/ --spawn "python server.py" --spawn-cwd path\to\rom
